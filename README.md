### Task 3 – Temperature Converter

An interactive temperature conversion website that allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

**Technologies Used:**
- HTML5
- CSS3
- Vanilla JavaScript

**Features:**
- Celsius, Fahrenheit and Kelvin conversion
- Numeric input validation
- Invalid input error handling
- Absolute-zero validation
- Displays converted values for all supported units
- Interactive Convert button
- Responsive design

📁 Project folder: `WebDev-L1-Temperature-Converter`
