# Personal Portfolio Website

A responsive personal portfolio website created as part of the Oasis Infobyte Web Development and Designing Internship – Level 1 Task 2.

## Features

- Responsive navigation bar
- Hero section with profile introduction
- About Me section
- Skills section
- Projects section
- Contact information section
- Smooth scrolling navigation
- Responsive design for desktop and mobile
- Clean and consistent visual design
- Built using HTML5 and CSS3
- Google Fonts
- CSS Flexbox and Grid
