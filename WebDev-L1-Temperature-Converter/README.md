# Temperature Converter Website

An interactive temperature converter website created as part of the Oasis Infobyte Web Development and Designing Internship – Level 1 Task 3.

## Features

- Convert temperatures between Celsius, Fahrenheit and Kelvin
- Numeric input validation
- Friendly error message for invalid input
- Absolute-zero validation
- Displays converted values for all supported units
- Interactive Convert button
- Responsive design for desktop and mobile
- Clean and centered user interface
- Built using HTML5, CSS3 and Vanilla JavaScript

## Conversion Units

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)
