# GlowSpace Landing Page

A responsive landing page created as part of the Oasis Infobyte Web Development and Designing Internship – Level 1 Task 1.

## Features

- Sticky navigation bar
- Hero section with call-to-action
- About, Features and Contact sections
- Responsive design for desktop and mobile
- Clean and consistent visual design
- Built using HTML5 and CSS3

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Google Fonts
