# Calculator — Level 2 Task 1

A fully functional browser-based calculator developed as part of the **Oasis Infobyte Web Development and Designing Internship — Level 2, Task 1**.

## 📌 Task Details

- **Organization:** Oasis Infobyte
- **Track:** Web Development and Designing
- **Level:** Level 2
- **Task:** Task 1 — Calculator
- **Project:** Calculator

## ✨ Features

- Numeric buttons from 0–9
- Decimal number support
- Addition, subtraction, multiplication and division
- Equals button for calculating results
- Clear button to reset the calculator
- Backspace button to delete the last entered character
- Operator chaining without resetting the calculator
- Division-by-zero protection with an error message
- Responsive calculator layout
- CSS Grid-based button layout
- Interactive buttons using JavaScript event listeners
- No inline `onclick` handlers
- No use of `eval()`

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- CSS Grid
